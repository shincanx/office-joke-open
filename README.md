Entry for the [make.fun bounty "Make the AI Judge Laugh: the Office Joke Open"](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232): a program that writes one single-line joke about office life (at most 200 characters) to `/output/entry.txt`.

## The joke

> Our office plant died, so facilities replaced it with a plastic one and a sign saying 'growth mindset'. It is the only thing in this office that has never missed a deadline.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network, no input. The program writes exactly the line above.
